## 新备份

```powershell
./scripts/local/Backup.ps1 -VerifyRestore
```

先检查没有活动任务，再暂停平台进程，保持 PostgreSQL 和所有接入项目运行状态不变。导出一致性数据库备份，复制白名单证明文件，生成文件与表级摘要；验证时创建独立数据库，运行 `pg_restore --exit-on-error --no-owner --no-privileges`，不启动任务处理器。备份完成后默认重新启动平台。

归档为独立时间戳目录，不覆盖已有归档。`-LeavePaused` 供维护窗口使用，结束后运行 `Start.ps1`。不归档 `.env`、密钥、账户截图、依赖目录或整个 `.runtime`。目录包含原始业务资料，请勿上传；需要另一磁盘副本时复制整个归档目录并校验清单。
